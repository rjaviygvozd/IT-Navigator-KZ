# IT Navigator KZ

Профориентационный Telegram-бот для учащихся 9–11 классов Казахстана.

Конкурсный педагогический проект учителя информатики СОШ №6 г. Павлодара. Бот помогает изучить IT-направления с помощью тестирования, дорожных карт, знакомства с вузами и тренировочных собеседований.

## Запуск

1. Создайте своего бота через @BotFather.
2. Установите Python 3.12 и зависимости: `pip install -r requirements.txt`.
3. Создайте файл `.env` по образцу `.env.example`; вставьте `BOT_TOKEN` только в `.env` или переменные окружения хостинга, **не в GitHub**.
4. Запустите: `python main.py`.

## Важно

Это учебный демонстрационный инструмент. Рекомендации по профессиям не являются психодиагностикой. Данные о поступлении и вузах нужно сверять с официальными источниками. Для непрерывной работы необходим сервер с постоянно запущенным процессом и постоянным хранилищем данных.

## Состояние

Репозиторий создан; загрузка полного исходного кода и интеграционная проверка Telegram ещё впереди.

## Постоянное хранение результатов

По умолчанию бот использует локальную SQLite, которая на бесплатном Render может очищаться при пересоздании экземпляра. Для PostgreSQL установите в Environment переменную `DATABASE_URL` со **внутренним URL** вашей БД Render; не помещайте URL в публичный репозиторий. Переключение не переносит прежние SQLite-результаты автоматически. Бесплатная PostgreSQL-база Render ограничена по сроку действия. Для долгой апробации необходимо заранее продумать платный либо иной постоянный вариант хранения.

## Команды координатора

`/myid` — узнать собственный Telegram ID. В Environment переменная `ADMIN_IDS` содержит числовые ID координаторов через запятую. После этого `/stats` показывает агрегированные результаты, без имён учеников.
